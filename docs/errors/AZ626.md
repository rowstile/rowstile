# AZ626: A policy applied by another version of rowstile

The command called an `authz.*` function that the policy in force doesn't have, or doesn't have with the arguments this version gives it: another version of rowstile applied that policy, and the message names it. The usual cause is a command upgraded and a database not yet. Make the database what this version makes: `rowstile reapply` on a database that doesn't take migrations; elsewhere `rowstile migrate`, then deploy the migration as any other. A function name rowstile doesn't make, or arguments no function takes, is said in Postgres's own words instead.

Reported by the command, against a database.
