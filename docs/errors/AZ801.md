# AZ801: A sync line that names nothing to sync

`sync schema.table : permission` keeps, for each row of a type's table, the keys that hold the permission on it, for sync engines. The table must be a type's, and the permission one of that type's. With no permission (`sync app.files`), the readers hold the table's select rule, so the table needs one. The readers table has a column `key`, so the type's key column can't be called `key` too.

Reported when the policy is compiled: `rowstile check`, the editor, `rowstile dev`.

## The mistake

```authz
app role app_user
type user = app.users
type file = app.files
  owner : user = owner_id
  can view = owner
sync role sync_engine
sync app.files : read
```

```
line 7: sync app.files : read: file has no permission read (it has: view) [AZ801]
```

## Fixed

```authz
app role app_user
type user = app.users
type file = app.files
  owner : user = owner_id
  can view = owner
sync role sync_engine
sync app.files : view
```
