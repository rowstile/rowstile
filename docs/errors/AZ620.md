# AZ620: No tables to draft a policy from

`rowstile init` drafts a first policy from the database's tables: those in the schemas `--schema` names, or, without it, those in every schema but Postgres's own and rowstile's. It found none there. Views aren't read, only tables. A schema's name may be wrong (`--schema` takes them as the catalog has them, `--schema app,billing`), the app's migrations may not have run yet, or the command is connected to another database than the app's (`--db`, `DATABASE_URL`).

Reported by the command, against a database.
