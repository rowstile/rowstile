# AZ722: SCIM settings that no longer hold

`authz.scim` met a setting, stored earlier with `authz.set_scim`, that is no longer true of the database: a column that was dropped or renamed, a function of the app's that is gone or was given to a role that isn't the policy's owner (it is called with the owner's rights, so it is called only while the owner owns it), or a function that answered something else than the key of the row it made or changed. The message says which. Nothing was written. It is the app's mistake, not the identity provider's: the SDKs leave it an error, a 500. Put right what the settings name, or set them again; `authz.lint()` lists the settings that no longer hold. SQLSTATE 55000.

Reported to the app, by the `authz.*` functions and the policy's rules: the code is in the error's HINT (`rowstile help AZ722`), and the SDKs' errors carry it as `code`.
