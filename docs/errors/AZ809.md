# AZ809: The sync role may read a masked column

A masked column (`mask body : edit`) is read through the masked view only. The sync role reads every row (it holds BYPASSRLS), so a masked column it may read would reach every client of the engine. Applying refuses it: revoke SELECT on the table from the sync role and grant the other columns, `GRANT SELECT (id, folder_id, name) ON app.files TO sync_engine`. `authz.lint()` reports a grant made since, and a publication that publishes a masked column.

Reported when the policy is applied (`rowstile push`, `apply`, a migration), against the database.
