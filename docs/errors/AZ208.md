# AZ208: A relation nothing uses

No permission, rule or invariant uses this relation, and no group subject (`team#member`) or roles line's `from` names it. It is often a typo in a second source of the same relation, or a permission not written yet. Use it, or remove it. A shared relation isn't refused: it is given at run time.

Reported when the policy is compiled: `rowstile check`, the editor, `rowstile dev`.

## The mistake

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner  : user = owner_id
  editor : user = editor_id
  can view = owner
```

```
line 5: folder.editor is declared but nothing uses it (no permission, rule, invariant, group or roles line refers to it): remove it, or if it is another source of an existing relation, give it that relation's name [AZ208]
```

## Fixed

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner  : user = owner_id
  editor : user = editor_id
  can view = owner or editor
```
