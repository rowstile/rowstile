# AZ622: A user table the draft can't use

The `user` type's key says who is signed in (`authz.act_as('user', '42')`), so it is one column, of a type rowstile can use as a key: bigint, integer, smallint, text, uuid or varchar. The table that holds the users here has a key of several columns (a tenant's and its own, often), or of another type. Name another table with `rowstile init --users schema.table`, or change the key.

Reported by the command, against a database.
