# AZ114: A quote that goes on to the next line

A string, a quoted name or a dollar quote in a condition ends on the line it starts on. The condition's text goes into the generated SQL, in its comments too, where a line break would end the comment. Write the text on one line, and a line break in a string as `E'\n'`: `'one' || E'\n' || 'two'`. A named test's statements (`given {...}`, `as user 3 allowed {...}`) may hold quotes over several lines: they are run as written.

Reported when the policy is compiled: `rowstile check`, the editor, `rowstile dev`.

## The mistake

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : user = owner_id
  can view = owner and {name <> 'one
    two'}
```

```
line 5: a quote in {...} goes on to the next line: write it on one line, a line break in a string as E'\n' ('a' || E'\n' || 'b') [AZ114]
```

## Fixed

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : user = owner_id
  can view = owner and {name <> 'one' || E'\n' || 'two'}
```
