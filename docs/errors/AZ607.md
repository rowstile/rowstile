# AZ607: The database holds the migration already, or isn't where it starts

Each policy migration starts from the policy the one before it left, recorded in `authz.policy_versions`. This database is somewhere else: a migration was skipped, or the database was changed with `rowstile push` or `apply` since. Apply the migrations in order; a database changed by `push` takes the migrations from the start, or `rowstile apply` of the policy the previous migration left. A development database that `rowstile dev` or `push` brought to the newest policy already holds what this migration brings, and the migration says so ("this database already holds what this migration brings"): don't run it there. Tell the migration tool it is applied, or make the database again from the migrations. Each tool keeps what ran in a table of its own. Alembic, Prisma and Django have a command that records a migration as applied; for the others, a row in that table does:

- Alembic: `alembic stamp head`.
- Prisma: `prisma migrate resolve --applied <the migration's folder>`, which also clears the failed migration Prisma kept.
- Django: `python manage.py migrate <app> <the migration> --fake`.
- Rails: `INSERT INTO schema_migrations (version) VALUES ('<the number its file name starts with>')`.
- Ecto: `INSERT INTO schema_migrations (version, inserted_at) VALUES (<the number its file name starts with>, now())`.
- Laravel: `INSERT INTO migrations (migration, batch) VALUES ('<its file name without .php>', <the last batch + 1>)`.
- EF Core: `INSERT INTO "__EFMigrationsHistory" ("MigrationId", "ProductVersion") VALUES ('<the id in its [Migration] attribute>', '<EF Core's version>')`.
- goose: `INSERT INTO goose_db_version (version_id, is_applied) VALUES (<its number>, true)`.
- dbmate: `INSERT INTO schema_migrations (version) VALUES ('<its number>')`.
- Drizzle Kit, Flyway and sqlx keep a hash of each migration's file with it: make the database again from the migrations.
- sql (files you run yourself): don't run this one there.

Reported when a policy migration runs.
