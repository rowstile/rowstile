# AZ630: A key compared by a collation that isn't deterministic

rowstile keeps ids as text and compares them as they are written. A text column under a collation that isn't deterministic (a case-insensitive one, say: `CREATE COLLATION ... deterministic = false`) holds `Bob` and `bob` as one key, and they are two ids to rowstile: a share made with one spelling finds the row and gives nothing, and stays when the row goes. Applying refuses such a key, with the column and its collation. Key the table by a column under a deterministic collation (the database's own is): its id, or a copy of the text in one spelling.

Reported when the policy is applied (`rowstile push`, `apply`, a migration), against the database.

## The mistake

```authz
app role app_user
type user = app.users
type tag = app.tags (name text)
  owner : user = owner_id
  can view = owner
```

## Fixed

```authz
app role app_user
type user = app.users
type tag = app.tags (id bigint)
  owner : user = owner_id
  can view = owner
```
