# AZ107: A name the policy can't use

Names can't contain `__`: generated names use it (`view__base`), and a policy can't refer to those. Nor can a name start or end with `_`: generated names join names with `__` (`folder__parent__view`), and `a` with `_p` would make the same name as `a_` with `p`. `signed_in`, `anyone`, `nobody`, `or`, `and`, `not`, `if` and `where` are words of the language, and a permission can't be called like a command (`select`, `insert`, `update`, `delete`). Choose another name.

Reported when the policy is compiled: `rowstile check`, the editor, `rowstile dev`.

## The mistake

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : user = owner_id
  can select = owner
```

```
line 5: 'select' is a command name; call the permission something else [AZ107]
```

## Fixed

```authz
app role app_user
type user = app.users
type folder = app.folders
  owner : user = owner_id
  can read = owner
```
