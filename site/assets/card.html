rowstile

Authorization inside your Postgres

Sharing, groups and nested folders in one policy file, compiled to row-level security.

rowstile.dev
type folder = app.folders
  owner  : user   = owner_id
  parent : folder = parent_id
  editor : user   = app.folder_editors(…)

  can edit = owner or editor or parent.edit
  can view = edit

rules app.folders
  select : view
  update : edit
